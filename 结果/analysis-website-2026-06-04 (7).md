### 第1章：都市之茧 — 焦虑的起点

**商业目标**：用户离开此 section 后，应该立刻理解“Diamond Rose Sanctuary”是一个为高压力人群提供身心疗愈的自然避世所。同时，让用户产生强烈的共鸣：“是的，我就是这种感觉。”

**故事角色**：**催化剂**。将用户从“日常”的麻木中拽出来，使其意识到自己正处于一种“隐性焦虑”的状态。

**情绪变化**：进入时：日常、平静、甚至有点无聊。离开时：被共鸣击中、感到一丝不安和渴望。

**画面描述**：画面始于一个极致的特写：雨滴砸在灰蓝色的柏油路面上，溅起细小的水花。镜头缓慢上摇，穿过拥挤的人潮（由模糊的、快速移动的色块构成），最终定格在一个玻璃幕墙大厦的顶层。透过模糊的窗户，一个西装革履的背影正瘫坐在办公椅上，窗外是灰蒙蒙的曼哈顿天际线。呼吸声在耳边放大，急促而沉重。

**内容文案**：
- **标题**：`你有多久没“呼吸”了？`
- **正文**：`这座城市每分钟都在向你索取。你的注意力、你的精力、你的睡眠。它把这叫做“效率”，而你，把这叫做“活着”。` （文案下方，一行小字缓缓浮现：`但活着，不该只是这样。`）
- **示例文字**：`每天 16 小时的清醒中，12 小时被屏幕占据。你的身体在办公室，你的心却不知流落何方。`

**动画叙事**：
1.  **呼吸同步**：页面的背景色调（从灰蓝到深灰）与一个微弱的呼吸动画（`scale: 0.98` 至 `1.02`）同步，让用户的第一感受是“被页面呼吸包裹”。
2.  **城市噪音的视觉化**：背景中，无数微小光点（代表城市信息流）在无序地闪烁和漂移，制造出一种视觉“噪音”。
3.  **人物剪影的孤独感**：窗口的剪影人物，通过 GSAP 实现极其缓慢的“垂头”动画（`rotate: 2deg`，持续 8 秒），暗示疲惫与放弃。
4.  **章节过渡**：当用户开始滚动时，整个画面像被一只无形的手擦拭，所有“城市元素”从中心向四周溶解（`opacity: 1` -> `0`, `filter: blur(0)` -> `blur(20px)`），同时背景色从 `--color-urban-gray` 平滑过渡到 `--color-forest-mist`。

**GSAP 关键代码**：
```javascript
// 1. 呼吸动画
const tlBreath = gsap.timeline({ repeat: -1, yoyo: true });
tlBreath.to('.hero-bg', { scale: 0.98, duration: 4, ease: 'power1.inOut' });

// 2. 滚动触发：城市溶解
ScrollTrigger.create({
  trigger: '.section-city',
  start: 'top top',
  end: 'bottom top',
  scrub: 1.5,
  onUpdate: (self) => {
    const progress = self.progress;
    gsap.to('.city-noise', { opacity: 1 - progress, duration: 0.1 });
    gsap.to('.hero-bg', { filter: `blur(${progress * 20}px)`, duration: 0.1 });
  }
});
```

**响应式**：移动端，背景简化为一张静态的城市雨景照片，呼吸动画改为一个脉动的圆形光晕。噪音粒子效果被移除。

**内容文案**：
- **标题**：`欢迎来到 Diamond Rose Sanctuary`
- **副标题**：`一片被意图守护的原始土地`

**动画叙事**：
1.  **对焦效果**：页面初始状态 `filter: blur(20px)`，随着滚动在 300ms 内变为 `blur(0)`。伴随一个“滴答”的清澈水声。
2.  **丁达尔光柱动画**：多个 `div` 模拟光线，从左上方向右下方倾斜。通过 GSAP 让它们的 `opacity` 在 0.1 到 0.4 之间随机脉动，制造出光线在空气中舞动的真实感。
3.  **文字逐词揭示**：章节标题的文字使用 SplitType 拆分为单词，每个单词从 `y: 20px` 和 `opacity: 0` 开始，依次弹跳到 `y: 0, opacity: 1`，间隔 50ms。
4.  **章节过渡**：当用户继续滚动，画面像被一个“镜头推近”，石阶和森林被放大，最终变为一片柔和的绿色背景（森林的内景），完成过渡。

**GSAP 关键代码**：
```javascript
// 1. 对焦动画
ScrollTrigger.create({
  trigger: '.section-arrival',
  start: 'top bottom',
  end: 'bottom 80%',
  scrub: 0.5,
  onUpdate: (self) => {
    gsap.to('.arrival-bg', { filter: `blur(${20 * (1 - self.progress)}px)`, duration: 0.1 });
  }

// 2. 丁达尔光效

  gsap.to(beam, {
    opacity: 0.4,
    duration: 1 + Math.random() * 2,
    yoyo: true,
    repeat: -1,
    ease: 'sine.inOut',
    delay: i * 0.3
  });
});
```

**响应式**：移动端，丁达尔光效简化为 2-3 条静态的、半透明的渐变条，文字动画保持，但速度加快。

**动画叙事**：
1.  **网格“点亮”**：四个网格初始状态为 `filter: grayscale(100%)` 和 `opacity: 0.3`。随滚动依次变为彩色、清晰。每个网格的“点亮”有 200ms 的延迟。

3.  **动态图标**：每个子模块前的图标（树叶、莲花、叶子）使用 GSAP 进行缓慢的旋转和缩放，模拟被微风吹拂。
4.  **章节过渡**：网格画面逐渐融化，变成一个全屏的、柔和的慢动作视频：一个人躺在草地上，胸口缓缓起伏。画面渐变为全白，过渡到下一章。

**GSAP 关键代码**：
```javascript
// 1. 网格点亮
const gridItems = document.querySelectorAll('.grid-item');
gridItems.forEach((item, i) => {

    trigger: item,
    start: 'top 85%',
    end: 'top 60%',
    scrub: 1,
    onUpdate: (self) => {
      gsap.to(item, {
        filter: `grayscale(${100 * (1 - self.progress)}%)`,
        opacity: 0.3 + 0.7 * self.progress,
        duration: 0.1
      });
    }
  });
});

// 2. 数字计数
const countObj = { val: 0 };
gsap.to(countObj, {
  val: 50,
  duration: 2,
  scrollTrigger: {
    trigger: '.stat-cell',
    start: 'top 80%',
    end: 'top 50%',
    scrub: 1
  },
  onUpdate: () => {
    document.querySelector('.stat-number').textContent = Math.round(countObj.val);
  }
});
```

**响应式**：移动端，2x2 网格变为垂直排列的四个卡片。数字计数动画保持。

**内容文案**：
- **标题**：`你的故事，下一章。`
- **正文**：`森林在等待。溪流在等待。那个更平静、更有力量的你，也在等待。`
- **CTA 按钮 1**：`✨ 预订你的静修之旅` (指向 `/booking`)
- **CTA 按钮 2**：`📖 探索 Alchemist 静修营` (指向 `/retreats`)
- **CTA 按钮 3**：`💬 预约免费咨询` (指向 `/contact`)
- **底部文字**：`无需预留。只需一个决定。`

**动画叙事**：
1.  **日落氛围**：背景色从 `--color-sunrise-peach` 缓慢渐变到 `--color-sunset-ember`，模拟时间流逝。
2.  **文字呼吸**：标题和正文文字随着背景色变化，产生极其微弱的 `scale: 1.02` 呼吸效果。
3.  **按钮吸引**：三个 CTA 按钮初始状态为 `opacity: 0, y: 30px`。当它们进入视口时，以 `stagger: 0.2` 的方式弹跳到最终位置。按钮自带一个微弱的金色辉光（`box-shadow`）动画，吸引点击。
4.  **章节过渡（结束）**：当用户不再滚动，页面底部的一个“返回顶部”按钮会以 `opacity: 0.3` 的状态出现，点击后整个页面会平滑滚动回顶部（`duration: 2, ease: 'power2.inOut'`），形成一个闭环。

**GSAP 关键代码**：
```javascript
// 1. 按钮入场
const ctas = gsap.utils.toArray('.cta-button');
ScrollTrigger.create({
  trigger: '.section-cta',
  start: 'top 70%',
  end: 'top 40%',
  scrub: 1,
  onUpdate: (self) => {
    ctas.forEach((cta, i) => {
      gsap.to(cta, {
        y: 30 * (1 - self.progress),
        opacity: 0 + self.progress,
        duration: 0.1,
        delay: i * 0.2
      });
    });
  }
});

// 2. 返回顶部按钮
const backToTop = document.querySelector('.back-to-top');
backToTop.addEventListener('click', () => {
  gsap.to(window, { duration: 2, scrollTo: { y: 0 }, ease: 'power2.inOut' });
});
```

**响应式**：移动端，三个 CTA 按钮垂直堆叠，并占据大部分屏幕宽度。

## 三、⚡ 故事高潮（2 个）

### 高潮1：从“城市”到“森林”的穿越之门

**它在故事中的位置**：第1章（都市之茧）和第2章（抵达）之间。

**用户做了什么**：在第一章末尾，用户继续向下滚动。当滚动的距离超过一个阈值（比如一个屏幕高度），奇迹发生了。

**发生了什么（分镜级描述）**：
```
0ms： 画面仍是第1章的灰蓝色城市雨景。用户的手指在触摸板/屏幕上滑动。
200ms：画面中央出现一个微小的、耀眼的白色光点，仿佛一粒尘埃。
400ms：光点迅速扩大，形成一个圆形的“门”，门的边缘是模糊的、跃动的光芒。
600ms：门内的景象开始呈现——是第2章的森林。用户透过这扇正在打开的“门”，看到了另一个世界。
1000ms：“门”完全打开，覆盖了整个屏幕。城市的一切细节被光芒吞噬。
1500ms：光芒开始消退，森林的细节逐渐显现。用户发现自己已经“穿越”了。
2000ms：画面稳定在第2章的开场：那条被苔藓覆盖的石阶。
```

**为什么用户会记住它**：这不是一个简单的过渡，这是一个“魔法时刻”。它用视觉上的“穿越之门”明确地告诉用户，你离开了旧世界，进入了一个全新的空间。这是整个叙事中最具仪式感的瞬间。

**完整 GSAP timeline 代码**：
```javascript
// 假设 .portal 是那个光门元素
const portalTl = gsap.timeline({
  scrollTrigger: {
    trigger: '.section-city',
    start: 'bottom top',
    end: 'bottom top', // 瞬间触发
    scrub: 0.5,
    // 非常关键：为了让过渡看起来是“瞬间”的，我们让 scrub 的进度变化非常快
  }
});

// 注意：为了精确控制，我们使用一个代理对象来驱动整个时间线
const proxy = { progress: 0 };
ScrollTrigger.create({
  trigger: '.section-city',
  start: 'bottom top',
  end: '+=1', // 只在 1px 的滚动距离内完成
  scrub: 0.3,
  onUpdate: (self) => {
    proxy.progress = self.progress;
  }
});

portalTl.to('.portal', {
  scale: 0,
  opacity: 0,
  duration: 0.01 // 初始状态隐藏
});

// 当 proxy.progress 变化时，我们控制 portal 的动画
// 但我们选择用另一个 ScrollTrigger 来驱动官方的 portal 动画，更稳定
ScrollTrigger.create({
  trigger: '.section-city',
  start: 'bottom top',
  end: '+=1',
  scrub: 0.5,
  onUpdate: (self) => {
    const p = self.progress;
    // 光门出现并扩张
    gsap.set('.portal', { scale: 0.01 + p * 100, opacity: p });
    // 背景变亮
    gsap.set('.hero-bg', { filter: `brightness(${1 + p * 2})` });
    // 城市元素消失
    gsap.set('.city-noise', { opacity: 1 - p });
    // 如果进度大于 0.8，开始显示森林背景
    if (p > 0.8) {
      gsap.set('.arrival-bg', { opacity: (p - 0.8) * 5 });
    }
  }
});
```

### 高潮2：数据“瀑布”的信任洪流

**它在故事中的位置**：第4章（证明）的开端。

**用户做了什么**：当用户滚动到“证明”章节，准备看数据时。

**发生了什么（分镜级描述）**：
```
0ms： 画面从第3章的柔和绿色瞬间切换为极简的灰白背景。所有元素消失。
200ms：屏幕上方，一个巨大的数字“0”开始向下“坠落”，仿佛从悬崖上掉下。
400ms：数字“0”在屏幕中央炸开，变成无数个微小的数字粒子（0-9），形成一个“数字瀑布”。
800ms：数字瀑布持续流淌了 1 秒钟，充满整个屏幕，制造出一种“信息洪流”的视觉冲击。
1200ms：数字瀑布突然停止。所有粒子瞬间凝固。
1500ms：粒子重新组合，形成了三个巨大的、清晰的数据数字：“92%”、“7,200+”、“0”。
2000ms：这三个数字落在对应的卡片上，卡片从底部滑入。数据章节正式开始。
```

**为什么用户会记住它**：它将枯燥的数据展示变成了一场令人屏息的“数字魔术”。用户不会忘记这个视觉奇观，因此也不会忘记这些数据。这比任何图表都更有说服力。

**完整 GSAP timeline 代码**：
```javascript
// 这需要 canvas 或大量 DOM 操作，我们使用 DOM + GSAP 来实现简化版
const waterfallTl = gsap.timeline({
  scrollTrigger: {
    trigger: '.section-proof',
    start: 'top 80%',
    end: 'top 30%',
    scrub: 1.5,
    // 确保在进入时触发，在结束前完成
  }
});

// 1. 初始状态设置
gsap.set('.waterfall-container', { opacity: 0 });
gsap.set('.proof-card', { y: 100, opacity: 0 });

// 2. 数字粒子（简化：使用 50 个 span 作为粒子）
const particles = document.querySelectorAll('.particle');
waterfallTl
  .to('.waterfall-container', { opacity: 1, duration: 0.1 })
  .fromTo(particles, { y: -100, opacity: 0 }, { 
    y: () => Math.random() * window.innerHeight, 
    opacity: 1, 
    duration: 0.8, 
    stagger: 0.01,
    ease: 'power2.in'
  })
  .to(particles, { opacity: 0, duration: 0.2 }, '+=0.2')
  .set('.proof-card', { y: 0, opacity: 1 }, '+=0.1')
  .fromTo('.proof-card .stat-number', { textContent: '' }, { 
    duration: 2, 
    stagger: 0.3,
    ease: 'power1.out',
    // 使用 onUpdate 来更新文本
    onUpdate: function() {
      // 注意：这里不能直接用 this.targets()，因为每个 card 需要不同的值
      // 建议为每个 card 创建独立的 timeline
    }
  }, '-=0.5');
```
