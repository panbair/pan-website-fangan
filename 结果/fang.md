# FAME 尊享地产服务 - 项目详细方案

## 一、项目概述

### 1.1 项目定位
FAME 是一家专注于中国高端房产投资服务的品牌，致力于为客户提供北京、上海、深圳及全国各大城市的优质房产甄选、投资咨询、交易支持和资产管理服务。

### 1.2 目标用户
- 高净值个人投资者
- 企业资产配置客户
- 寻求优质房产的精英阶层
- 房产投资新手（需要专业指导）

### 1.3 核心价值主张
- **专业甄选**：深度分析国内房产市场，精选优质项目
- **全程服务**：从选房到交房一站式全流程服务
- **VIP体验**：私人定制服务，尊贵体验
- **资产增值**：专业管理，最大化投资回报

## 二、技术架构

### 2.1 技术栈
- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite 7
- **UI组件库**：shadcn/ui (基于 Radix UI)
- **样式方案**：Tailwind CSS v4
- **路由方案**：TanStack Router (文件路由)
- **动画库**：GSAP + ScrollTrigger
- **平滑滚动**：Lenis
- **图标库**：Lucide React

### 2.2 项目结构
```
src/
```

## 四、设计系统

### 4.1 色彩方案
```css
/* 主色调 */
--primary: #d4a853;        /* 金色 - 奢华感 */
--primary-foreground: #1a1a1a;

/* 背景色 */
--background: #0a0a0a;     /* 深色背景 */
--background-secondary: #111111;

/* 文字色 */
--foreground: #f5f5f5;      /* 主文字 */
--foreground-muted: #a1a1a1; /* 次要文字 */

/* 边框色 */
--border-subtle: rgba(255,255,255,0.1);
```

### 4.2 字体规范
- **标题字体**：系统默认 Display 字体
- **正文字体**：系统默认 Sans 字体
- **字号层级**：
  - Hero: 4rem+
  - Display: 3rem
  - Headline: 2rem
  - Title: 1.5rem
  - Body: 1rem
  - Caption: 0.875rem
  - Label: 0.75rem

### 4.3 间距系统
- **Section间距**：py-32 (8rem)
- **容器宽度**：max-w-[90vw]
- **卡片间距**：gap-6 ~ gap-8
- **内边距**：p-6 ~ p-10

### 4.4 组件样式

#### 玻璃态效果 (Glass)
```css
.glass {
  background: rgba(255,255,255,0.05);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255,255,255,0.1);
}
```

#### 按钮样式
- **Filled按钮**：实心金色背景
- **Luxury按钮**：透明背景+金色边框

#### 卡片样式
- **Card Luxury**：圆角+边框+悬停效果
- **Glass卡片**：玻璃态+阴影
