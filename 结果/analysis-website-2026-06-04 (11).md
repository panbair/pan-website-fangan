## 二、📖 故事章节（逐 Section）

### 第一章：Hero — 第一次呼吸

**商业目标**：用户在 3 秒内理解：这是一个关于“时间暂停”和“内在回归”的高端沉浸式体验品牌，目标用户是寻求深度解脱的都市高压人群。

**故事角色**：一个疲惫的都市人（用户的镜像）。情绪从“迷失”到“第一次被震撼”。

**画面描述**（120 字电影分镜）：

画面从一片漆黑开始，像闭上眼睛后的黑暗。三秒后，一声铜锣的余音（低频震动）响起，画面从中心向外扩散出微光——光晕像水墨滴入清水般缓慢扩散。光晕中浮现出一个模糊的身影轮廓，站在悬崖边缘。镜头极慢地拉远（约 6 秒），露出脚下翻涌的云海。云海像活着的有机体在缓慢呼吸。右上角，品牌名「VELORA RISE」以手写墨迹风格逐笔出现，每个笔画像树枝生长。标题居中，距顶部 240px，字号 96px。副标题在标题下方 32px 处，字号 20px，字间距 8px。底部有一个极细的“Scroll to enter”指示线，以呼吸节奏明暗闪烁。

**内容文案**：

> **主标题**：VELORA RISE
> **副标题**：A Sanctuary for Time, Not for Schedules
> **正文引出**：在城市的混凝土缝隙里，你有多久没有听见自己的呼吸了？

**动画叙事**（5 种动画 + 章节过渡）：

1. **光晕扩散动画**：Canvas 2D 绘制径向渐变，模拟墨水入水效果，持续 4 秒后淡出
2. **品牌名手写揭示**：SplitType 将 VELORA RISE 拆分为单个字母，每个字母的笔画使用 GSAP 的 `drawSVG` 插件从无到有画出，间隔 200ms，总时长 3 秒
3. **云海视差呼吸**：背景云海图片（超大尺寸 1920x1080）在滚动时以 0.3 倍速做垂直平移，同时叠加一个缓慢的 scale 动画（1.0 → 1.05），模拟呼吸感
4. **“Scroll to enter”指示线**：使用 CSS `@keyframes` 做 opacity 0→1→0 的呼吸循环，周期 2.5 秒
5. **章节过渡**：当用户开始滚动时，整个 Hero 画面以“被风吹散”的效果过渡——文字变成碎片向右飘散，云海模糊消失，进入下一章

**GSAP 关键代码**：

```javascript
// 品牌名手写揭示
gsap.registerPlugin(ScrollTrigger, SplitType, DrawSVGPlugin);

// 准备品牌名
const brandTitle = new SplitType('#hero-title', { types: 'chars' });

// 每个字母的 SVG 路径动画
const brandTimeline = gsap.timeline({ delay: 3 });
brandTitle.chars.forEach((char, i) => {

  const path = char.querySelector('path');
  if (path) {
    brandTimeline.fromTo(path, 
      { drawSVG: '0%' },
      { drawSVG: '100%', duration: 1, ease: 'power2.out' },
      i * 0.2
    );
  }
});

// 云海呼吸动画（滚动控制）
gsap.to('.hero-clouds', {
  scale: 1.05,
  y: '-5%',
  scrollTrigger: {
    trigger: '.hero',
    start: 'top top',
    end: 'bottom top',
    scrub: 0.5
  }
});

// 章节过渡：文字碎片飘散
gsap.to('.hero-text-wrapper', {
  opacity: 0,
  x: '100%',
  stagger: 0.05,
  ease: 'power4.in',
  scrollTrigger: {
    trigger: '.hero',
    start: 'bottom bottom',
    end: 'bottom top',
    scrub: 1
  }
});

// Canvas 光晕动画
const canvas = document.querySelector('#hero-canvas');
const ctx = canvas.getContext('2d');
const dpr = window.devicePixelRatio || 1;
canvas.width = canvas.offsetWidth * dpr;
canvas.height = canvas.offsetHeight * dpr;
ctx.scale(dpr, dpr);

// 光晕参数
let glowRadius = 0;
let glowOpacity = 0;
const centerX = canvas.width / 2;
const centerY = canvas.height / 2;

function drawGlow() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  
  // 径向渐变模拟墨水扩散
  const gradient = ctx.createRadialGradient(centerX, centerY, 0, centerX, centerY, glowRadius);
  gradient.addColorStop(0, `rgba(92, 138, 110, ${glowOpacity})`);
  gradient.addColorStop(0.3, `rgba(45, 74, 55, ${glowOpacity * 0.6})`);
  gradient.addColorStop(0.7, `rgba(15, 26, 19, ${glowOpacity * 0.2})`);
  gradient.addColorStop(1, 'rgba(15, 26, 19, 0)');
  
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  
  requestAnimationFrame(drawGlow);
}

// GSAP 控制光晕动画
gsap.to({ val: 0 }, {
  val: canvas.width * 0.6,
  duration: 4,
  ease: 'power2.out',
  onUpdate: function() {
    glowRadius = this.targets()[0].val;
    glowOpacity = Math.min(this.targets()[0].val / (canvas.width * 0.3), 1);
  }
});

// 窗口 resize
window.addEventListener('resize', () => {
  canvas.width = canvas.offsetWidth * dpr;
  canvas.height = canvas.offsetHeight * dpr;
  ctx.scale(dpr, dpr);
});

drawGlow();
```

- 手机（<768px）：标题 40px，去除手写笔画动画（性能），改用 fade-in，光晕 canvas 缩小至 60% 尺寸

### 第二章：数字噪音 — 你被困在哪里？

**商业目标**：让用户意识到“我需要改变”——通过共鸣（看到自己的影子）产生需求。

**故事角色**：还是那个都市人，但这次我们看到他的“日常地狱”。情绪：焦虑 → 窒息 → 渴望。

**画面描述**（130 字电影分镜）：

画面从极近的微距开始：手机屏幕上的通知栏，图标在疯狂跳动——邮件、微信、Slack、日历提醒...每个通知像病毒一样复制、膨胀、爆炸。镜头缓慢拉开（3 秒），我们看到这是一个人躺在床上，手机的光照亮他/她疲惫的脸。房间的墙壁上投射着无数数字虚影——会议室的 Zoom 格子、地铁里刷屏的人群、凌晨两点还在闪烁的电脑屏幕。这些虚影像幽灵一样在空间里漂浮、碰撞。最后，所有噪音在一个“静音”图标出现时戛然而止——画面陷入完全的黑暗和寂静，只留下一个微弱的呼吸声。标题「The Noise Before the Silence」以像素化→清晰的效果出现。

**内容文案**：

> **主标题**：The Noise Before the Silence
> **正文**：研究表明，普通人每天接收 34GB 的信息量，相当于 174 份报纸。你的大脑从未像现在这样——被训练成只能“反应”，不能“存在”。
> **引语**：“我怀念那个不需要解释‘为什么我这么累’的时刻。”

**动画叙事**（4 种动画 + 章节过渡）：

1. **通知爆炸动画**：Canvas 2D 粒子系统 — 每个通知图标作为一个粒子（共 200+ 个），从中心向外爆炸，然后随机漂浮。使用 requestAnimationFrame 驱动
2. **数字虚影投影**（高级手法 — 光影扫过）：房间墙壁上使用 `mix-blend-mode: screen` 叠加层，通过 CSS `clip-path` 动画模拟“光扫过墙壁”的效果。每 4 秒循环一次
3. **标题像素化→清晰**（基础手法 — blur→sharp）：SplitType 将标题拆为单词，每个单词初始 `filter: blur(10px)`，在滚动过程中逐个变为清晰
4. **章节过渡**：黑暗持续 2 秒后，画面从中心裂开一道光——像撕开黑幕，进入下一章

**GSAP 关键代码**：

```javascript
// Canvas 通知粒子系统
const particleCanvas = document.querySelector('#noise-canvas');
const pCtx = particleCanvas.getContext('2d');
const pDpr = window.devicePixelRatio || 1;
particleCanvas.width = particleCanvas.offsetWidth * pDpr;
particleCanvas.height = particleCanvas.offsetHeight * pDpr;
pCtx.scale(pDpr, pDpr);

// 粒子类
class NotificationParticle {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.vx = (Math.random() - 0.5) * 4;
    this.vy = (Math.random() - 0.5) * 4;
    this.size = Math.random() * 20 + 10;
    this.opacity = 1;
    this.life = 1;
    this.decay = 0.002 + Math.random() * 0.003;
    this.rotation = Math.random() * 360;
    this.rotationSpeed = (Math.random() - 0.5) * 2;
  }

  update() {
    this.x += this.vx;
    this.y += this.vy;
    this.life -= this.decay;
    this.opacity = this.life;
    this.rotation += this.rotationSpeed;
    return this.life > 0;
  }

  draw(ctx) {
    ctx.save();
    ctx.globalAlpha = this.opacity;
    ctx.translate(this.x, this.y);
    ctx.rotate(this.rotation * Math.PI / 180);
    // 画一个简单的通知图标
    ctx.fillStyle = '#C49A6C';
    ctx.fillRect(-this.size/2, -this.size/2, this.size, this.size * 0.8);
    ctx.fillStyle = '#F5F0E8';
    ctx.fillRect(-this.size/4, -this.size/4, this.size/2, this.size/4);
    ctx.restore();
  }
}

let particles = [];
const centerX = particleCanvas.width / 2;
const centerY = particleCanvas.height / 2;

// 爆炸函数
function explode() {
  for (let i = 0; i < 200; i++) {
    particles.push(new NotificationParticle(centerX, centerY));
  }
}

// 每 4 秒爆炸一次
setInterval(explode, 4000);
explode(); // 初始爆炸

function animateParticles() {
  pCtx.clearRect(0, 0, particleCanvas.width, particleCanvas.height);
  
  particles = particles.filter(p => p.update());
  particles.forEach(p => p.draw(pCtx));
  
  requestAnimationFrame(animateParticles);
}

animateParticles();

// 标题像素化→清晰
gsap.from('.noise-title .word', {
  filter: 'blur(10px)',
  opacity: 0,
  y: 20,
  stagger: 0.15,
  duration: 1,
  ease: 'power2.out',
  scrollTrigger: {
    trigger: '.noise-section',
    start: 'top 80%',
    end: 'center center',
    scrub: 0.5
  }
});

// 数字虚影光影扫过
gsap.to('.digital-ghost', {
  clipPath: 'inset(0% 0% 0% 100%)',
  duration: 4,
  repeat: -1,
  ease: 'power1.inOut',
  yoyo: true
});

// 章节过渡：黑暗裂开
gsap.to('.noise-section', {
  clipPath: 'inset(0% 0% 100% 0%)',
  scrollTrigger: {
    trigger: '.noise-section',
    start: 'bottom center',
    end: 'bottom top',
    scrub: 1
  }
});
```

**响应式**：
- 桌面：全屏效果，粒子 200 个
- 平板：粒子减少至 100 个，取消光影扫过（性能）
- 手机：粒子减少至 50 个，标题 blur 动画改为简单的 opacity 动画

### 第三章：Velora 的诞生 — 一个关于“暂停”的故事

**商业目标**：建立品牌的情感根基——告诉用户“这不是一个度假村，而是一个使命”。让用户信任创始人的初心。

**故事角色**：创始人 Lena Velora（一个真实的人物形象）。情绪：从“疲惫”到“觉醒”到“决心”。

**画面描述**（140 字电影分镜）：

画面从一本泛黄的笔记本翻开开始，页面上的手写文字「I just need to stop.」——墨水在纸上晕开，变成一条河流。镜头顺着河流流动（使用横向滚动），画面像一幅水墨卷轴在展开。卷轴上依次出现：Lena 在办公室里疲惫地看窗外、她在山里第一次看到日出时的泪眼、她坐在木屋前书写、她和工匠一起建造 Velora 的场景。每个场景都是静止的图片，但通过 ScrollTrigger 控制它们像“翻书”一样出现。最后，卷轴尽头出现一座被晨雾环绕的木制建筑群——Velora Rise。标题「A Place That Waited for You」以逐词浮现的方式出现。

**内容文案**：

> **主标题**：A Place That Waited for You
> **正文**：Lena Velora 曾是纽约最年轻的合伙人律师。32 岁那年，她在时代广场中央突然无法呼吸——不是因为空气，而是因为“从未真正呼吸过”。她卖掉了公寓，带着一本《瓦尔登湖》和一张地图，走进了卡茨基尔山脉深处。三个月后，她在一块被遗忘的土地上醒来，周围是鹿和晨雾。她说：“不是找到了这个地方——是这个地方找到了我。”
> **引语**：“我们不建造度假村。我们守护那些能让时间变慢的地方。”

**动画叙事**（4 种动画 + 章节过渡）：

1. **卷轴展开效果**（基础手法 — parallax分层）：整个 section 使用水平滚动（`horizontal: true`），5 张图片作为卷轴的不同片段，以不同的速度和 Z 轴位置滚动，创造深度感
2. **墨迹晕染过渡**（高级手法 — 水墨晕染）：每个场景之间的过渡使用 Canvas 2D 绘制水墨晕染效果——用 `ctx.globalCompositeOperation = 'destination-in'` 模拟墨水在宣纸上扩散
3. **逐词浮现**：标题使用 SplitType 拆为单词，每个单词从 `opacity: 0, y: 30` 渐入，但每个单词之间有一个“停顿”——模拟说话时的呼吸节奏
4. **章节过渡**：卷轴尽头，画面开始“呼吸”——整体 scale 在 0.95-1.05 之间缓慢脉动，然后 fadeOut 进入下一章

// Canvas 水墨晕染过渡
function inkSplash(ctx, width, height, progress) {
  ctx.clearRect(0, 0, width, height);
  
  // 水墨纹理
  const gradient = ctx.createRadialGradient(width/2, height/2, 0, width/2, height/2, width * 0.4 * progress);
  gradient.addColorStop(0, 'rgba(15, 26, 19, 0.8)');
  gradient.addColorStop(0.3, 'rgba(15, 26, 19, 0.4)');
  gradient.addColorStop(0.7, 'rgba(15, 26, 19, 0.1)');
  gradient.addColorStop(1, 'rgba(15, 26, 19, 0)');
  
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, width, height);
  
  // 模拟墨水边缘的扩散
  for (let i = 0; i < 50; i++) {
    const x = width/2 + (Math.random() - 0.5) * width * 0.6 * progress;
    const y = height/2 + (Math.random() - 0.5) * height * 0.6 * progress;
    const r = Math.random() * 10 * progress;
    ctx.beginPath();
    ctx.arc(x, y, r, 0, Math.PI * 2);
    ctx.fillStyle = `rgba(15, 26, 19, ${Math.random() * 0.3 * progress})`;

// Canvas 动态星空
const starCanvas = document.querySelector('#star-canvas');
const starCtx = starCanvas.getContext('2d');
const starDpr = window.devicePixelRatio || 1;
starCanvas.width = starCanvas.offsetWidth * starDpr;
starCanvas.height = starCanvas.offsetHeight * starDpr;
starCtx.scale(starDpr, starDpr);

class Star {
  constructor() {
    this.x = Math.random() * starCanvas.width;
    this.y = Math.random() * starCanvas.height;
    this.size = Math.random() * 2 + 0.5;
    this.twinkleSpeed = Math.random() * 0.02 + 0.005;
    this.twinklePhase = Math.random() * Math.PI * 2;
    this.baseOpacity = Math.random() * 0.8 + 0.2;
    this.vx = (Math.random() - 0.5) * 0.1;
    this.vy = (Math.random() - 0.5) * 0.1;
  }

  update(btnX, btnY, isHovering) {
    this.x += this.vx;
    this.y += this.vy;
    
    if (isHovering && btnX && btnY) {
      const dx = btnX - this.x;
      const dy = btnY - this.y;
      const dist = Math.sqrt(dx * dx + dy * dy);
      if (dist < 200) {
        this.vx += dx * 0.0005;
        this.vy += dy * 0.0005;
      }
    }
    
    // 边界
    if (this.x < 0) this.x = starCanvas.width;
    if (this.x > starCanvas.width) this.x = 0;
    if (this.y < 0) this.y = starCanvas.height;
    if (this.y > starCanvas.height) this.y = 0;
  }

  draw(ctx, time) {
    const twinkle = Math.sin(time * this.twinkleSpeed + this.twinklePhase) * 0.5 + 0.5;
    const opacity = this.baseOpacity * (0.5 + 0.5 * twinkle);
    
    ctx.beginPath();
    ctx.arc(this.x, this.y, this.size, 0, Math.PI * 2);
    ctx.fillStyle = `rgba(245, 240, 232, ${opacity})`;
    ctx.fill();
  }
}

const stars = Array.from({ length: 500 }, () => new Star());
let hoveredBtn = null;

document.querySelectorAll('.cta-btn').forEach(btn => {

    hoveredBtn = btn;

function animateStars() {

  stars.forEach(star => {
    star.update(btnX, btnY, !!hoveredBtn);
    star.draw(starCtx, time);
  });

}
