# 🌊 TERRA NOVA — 在遗忘中重新发现呼吸

> **灵感来自**：diamondrosesanctuary.com 的诗意叙事与滚动驱动的电影感体验 + 其哲学化文案与精神疗愈定位的完美融合
> **故事主线**：一个被数字世界淹没的灵魂，穿越迷雾森林，最终在原始自然的怀抱中找回了遗忘的呼吸节律。
> **情绪曲线**：窒息的焦虑 → 迷茫的探索 → 震撼的觉醒 → 深沉的疗愈 → 宁静的承诺

## 一、🎨 视觉世界观

### 1.1 情绪板

想象你站在一个雨后的古老森林入口。雾气从地面缓缓升起，阳光透过层层叠叠的树叶，在苔藓上投下斑驳的光影。远处传来溪水的声音，空气里是松脂和泥土的气息。你正站在两个世界的交界处——一个是钢铁与屏幕的丛林，一个是万物有灵的原始王国。

这个网站就是那道门。当用户第一次打开页面，他们看到是极简的、近乎空旷的界面，但每滚动一寸，世界就活过来一寸。文字从雾中浮现，树木在视野边缘生长，光线随着滚动的深度变换色彩。这不是一个网页，而是一个通向内在宁静的入口。

## 二、📖 故事章节（逐 Section）

### 第一章：迷雾（The Fog）

**故事角色**：建立问题——用户进入时感受到的是日常的窒息感

**用户情绪**：[被信息淹没的焦虑] → [好奇的探索欲]

**画面描述**：
首屏是一片近乎抽象的深绿色迷雾。背景是一层又一层缓慢脉动的粒子，像无数微小的尘埃在空气中漂浮。画面极暗，只在中心有一点微光，像一个呼吸的节奏在闪烁。

前景是一行几乎看不见的文字，被雾气完全包裹，只有当你屏住呼吸凝视时，才能隐约辨认出轮廓。在画面底部，有一条水平线——那是地平线，也是迷雾的边界。随着滚动，这条线会缓缓上升，像是在破晓。

光线是冷峻的，带着暗绿色的冷光，像深海里的生物荧光。整个画面给人一种被包围、被包裹的感觉——不是恐惧，而是一种安全的、子宫般的黑暗。

**内容文案**：
- 标题方向：极简、抽象、只用一个词或一个短句。“Breathe.” / “Remember.” / “Before.”
- 正文方向：像内心独白，直接与用户的焦虑对话。“你有多久没有真正呼吸了？不是那种在会议室里压抑的、在通勤路上急促的、在深夜里被手机屏幕照亮的呼吸。而是那种——从脚底升起、漫过脊椎、填满整个胸腔的呼吸。”

**动画叙事**：
- **主导动画**：5层粒子视差系统。第一层（最近的）移动最快，第五层（最远的）几乎静止。每层粒子的大小、透明度、移动速度都不同，创造出走入浓雾的深度感。粒子在滚动中逐渐散开，像雾被风吹散。
- **文字动画**：标题使用 SplitType 拆分成单个字符。每个字符从 blur(20px) 到 blur(0)，opacity 从 0 到 1，逐字浮现。每两个字之间间隔 0.08s，像露珠从叶尖滑落。
- **氛围动画**：中央微光是一个圆形渐变，脉动周期与人类静息呼吸频率同步（约 4s 一个周期）。脉动幅度随滚动加深而增大，从隐约可见到几乎照亮整个画面。
- **元素联动**：文字浮现后 0.3s，底部地平线开始上升。地平线是一条渐变线，从深绿到金色。它的上升速度是文字的 0.7x，创造出时间差。
- **过渡到下一章**：当滚动到达 80% 时，所有粒子层的 opacity 开始同步下降（1→0），但下降速度不同：近层快，远层慢。同时，背景色从 #1A2F1D 渐变到 #4A7C59。这个过程持续 1.2s 的滚动距离，用户会感觉像是穿过了迷雾的边界。

**GSAP 关键代码**：
```javascript
// 粒子层
const layers = document.querySelectorAll('.particle-layer');
const tl = gsap.timeline({
  scrollTrigger: {
    trigger: '.hero',
    start: 'top top',
    end: 'bottom top',
    scrub: 1.5
  }
});

layers.forEach((layer, i) => {
  const speed = 0.2 + (i * 0.15);
  tl.to(layer, {
    y: () => -window.innerHeight * speed,
    opacity: 1 - (i * 0.15),
    ease: 'none'
  }, 0);
});

// 文字
const chars = document.querySelectorAll('.hero-title .char');
chars.forEach((char, i) => {
  gsap.fromTo(char, 
    { filter: 'blur(20px)', opacity: 0 },
    {
      filter: 'blur(0px)', opacity: 1,
      scrollTrigger: {
        trigger: '.hero',
        start: 'top top',
        end: '+=40%',
        scrub: 0.5
      }
    }
  );
});

// 呼吸光
const c = { progress: 0 };
gsap.to(c, {
  progress: 1,
  scrollTrigger: {
    trigger: '.hero',
    start: 'top top',
    end: 'bottom top',
    scrub: true
  },
  onUpdate: () => {
    const breathe = Math.sin(c.progress * Math.PI * 2) * 0.3 + 0.5;
    document.querySelector('.breathing-light').style.opacity = breathe;
  }
});
```

- 桌面：5层粒子全显示，文字字号 72px，呼吸光直径 300px
- 平板：3层粒子，文字字号 48px，呼吸光直径 200px
- 手机：2层粒子，文字字号 36px，呼吸光直径 150px，粒子密度减半

### 第二章：迷途（Lost）

**故事角色**：深化困境——用户意识到自己迷失在数字世界的程度

**用户情绪**：[好奇的探索欲] → [不安的共鸣]

**画面描述**：
背景变成一片由无数细线构成的抽象网络——像城市的地铁图、或者神经元的连接。这些线在缓慢地、无休止地脉动，每一条线都在闪烁着微弱的光。这是数字世界的隐喻。

前景中，一个人影（用抽象的几何形状代表）站在网络的中心，被无数条线包围。他的轮廓模糊，像是快要被这些线吞噬。但他的胸口有一处微光——那是还活着的部分。

文字出现在画面左侧，像是从网络缝隙中生长出来的。字体比第一章更大，但依然带着轻微的模糊，像是你在水下看东西。

画面的色调从绿色转向了灰蓝色，带着金属的冷感。网络线的脉动频率在加快，像心跳过速。

**内容文案**：
- 标题方向：自问自答式。“你在这里吗？” / “当信号消失的时候”
- 正文方向：描述数字异化的具体场景。“你记得上一次不看手机吃完一顿饭是什么时候吗？上一次不带着耳机走路？上一次在深夜闭上眼，脑海里没有工作群的消息在滚动？这不是你的错。这是这个时代的空气。”

**动画叙事**：
- **主导动画**：网络线系统——约 30 条曲线，每条都有独立的移动路径和脉动频率。使用 `<canvas>` 绘制，每帧更新位置。滚动时，线的密度从中心向外发散，创造“被包围”的感觉。
- **文字动画**：标题使用 SplitType 拆分为单词。每个单词从左侧滑入（x: -100px → 0），同时 opacity 0→1。但滑入速度不同：第一个单词快，最后一个慢，创造出一种“挣扎着要说完”的感觉。
- **人物动画**：中心人物使用 SVG 路径动画。他的轮廓在滚动中逐渐清晰（从模糊到锐利），胸口的微光渐变扩大。当滚动到 50% 时，他会微微抬起右手——这是一个“尝试触碰”的动作。
- **环境动画**：背景的灰蓝色调在滚动中逐渐褪去，露出底下的绿色。这是“记忆正在复苏”的暗示。
- **过渡到下一章**：当滚动到达 70% 时，网络线开始断裂。不是一下子全部断裂，而是一条一条地、像琴弦断裂一样。每断一条，画面中就多出一小块绿色。这个过渡持续 1.5s 的滚动距离。

**GSAP 关键代码**：
```javascript
// Canvas 网络线
const canvas = document.querySelector('.network-canvas');
const ctx = canvas.getContext('2d');
const lines = [];
for (let i = 0; i < 30; i++) {
  lines.push({
    points: Array.from({length: 5}, () => ({
      x: Math.random() * canvas.width,
      y: Math.random() * canvas.height
    })),
    speed: 0.5 + Math.random() * 1.5,
    opacity: 0.3 + Math.random() * 0.7,
    phase: Math.random() * Math.PI * 2
  });
}

let scrollProgress = 0;
const anim = gsap.to({p: 0}, {
  p: 1,
  scrollTrigger: {
    trigger: '.lost-section',
    start: 'top top',
    end: 'bottom top',
    scrub: true,
    onUpdate: (self) => { scrollProgress = self.progress; }
  }
});

function drawLines() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  lines.forEach((line, i) => {
    ctx.beginPath();
    ctx.strokeStyle = `rgba(61, 90, 92, ${line.opacity * (1 - scrollProgress)})`;
    ctx.lineWidth = 1;
    const t = scrollProgress * line.speed + line.phase;
    line.points.forEach((p, j) => {
      const x = p.x + Math.sin(t + j) * 50;
      const y = p.y + Math.cos(t * 0.7 + j) * 50;
      j === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
    });
    ctx.stroke();
  });
  requestAnimationFrame(drawLines);
}
drawLines();

// 文字
gsap.from('.lost-title .word', {
  x: -100, opacity: 0,
  stagger: 0.15,
  scrollTrigger: {
    trigger: '.lost-section',
    start: 'top 30%',
    end: 'center center',
    scrub: 1
  }
});

// 人物手部动作
gsap.to('.figure-arm', {
  rotation: -15,
  y: -20,
  scrollTrigger: {
    trigger: '.lost-section',
    start: '40% center',
    end: '60% center',
    scrub: true
  }
});
```

**响应式**：
- 桌面：30条网络线，人物 SVG 完整显示
- 平板：20条线，人物简化
- 手机：12条线，人物只保留轮廓和胸口微光

### 第三章：初醒（First Light）

**故事角色**：转折点——用户看到逃离的可能性

**用户情绪**：[不安的共鸣] → [希望的光芒]

**画面描述**：
画面从灰蓝色瞬间切换——不对，不是瞬间，而是一个缓慢的、像水彩晕开的渐变。网络线断裂后留下的空隙中，绿色的光渗透进来，像黎明前天空最微弱的鱼肚白。

背景变成一片森林的剪影——不是具体的树，而是树的意象：垂直的线条，层次分明的明暗。远处有光，从树缝间射进来，形成一道道光束。

前景中，一条小径出现了。它不是清晰的路，而是一条由落叶和光影暗示出来的路径。小径弯弯曲曲，消失在森林深处。

文字出现在光束中，像被光照亮。字体是温暖的、金色的，带着轻微的发光效果。

画面中开始出现细节：一片飘落的叶子、一只蝴蝶的剪影、远处的水面反射。这些细节不是同时出现的，而是随着滚动一一浮现。

**内容文案**：
- 标题方向：诗意的觉醒。“The Forest Remembers.” / “Before You Were Wired.”
- 正文方向：从抽象到具体的过渡。“在人类的记忆深处，有一条路。它不是谷歌地图上的蓝线，不是导航APP里的虚线。它是你祖先走过的路——穿过森林、越过溪流、在星空下扎营。这条路从未消失，它只是在等你重新找到它。”

**动画叙事**：
- **主导动画**：森林剪影的视差系统——5层剪影（最近→最远），每层速度不同。最近层移动最快，最远层几乎静止。每层之间有小间隙，当滚动时，这些间隙产生空间感。
- **光束动画**：6道光束从树顶射入，角度不同。使用 CSS clip-path 创建光束形状。每道光束的 opacity 和 width 随滚动变化，创造出“光线在移动”的效果。
- **小径动画**：小径是一条 SVG 路径，初始 opacity 0，随着滚动逐渐显现。路径的描边长度（stroke-dashoffset）从 100% 到 0%，像路在脚下被照亮。
- **细节浮现**：叶子、蝴蝶、水面反射等细节元素，每个都有独立的 scrollTrigger。它们在不同滚动位置出现，创造“边走边发现”的节奏。
- **过渡到下一章**：当滚动到 85% 时，森林剪影开始向两侧移动（像打开一扇门），露出下一章的背景。光束汇聚成一道更强的光，引导视线进入。

### 第四章：觉醒（Awakening）【故事高潮 #1】

**故事角色**：第一个高潮——用户体验到“离开数字世界”的生理性快感

**用户情绪**：[希望的光芒] → [心被打开的震撼]

**画面描述**：
这是整个故事中最震撼的瞬间。当用户滚动到这一章的开头时——突然之间，画面从深色完全翻转。

背景变成一片温暖的金色——不是刺眼的阳光，而是黄昏时那种蜂蜜色的、可以直视的光。整个画面像是被浸泡在光里。

前景中，一棵巨大的树占据了画面的中心。这不是普通的树——它的树干是半透明的，你能看到内部流动着金色的光，像血液一样在树的脉络中循环。树枝伸向四面八方，每一根枝条末端都有一点微光——像是星星。

树的周围，无数光点从地面升起。它们不是规则的，而是像萤火虫一样，有的快有的慢，有的直线上升，有的蜿蜒曲折。这些光点越来越多，直到填满整个画面。

文字出现在树干的右侧，字体是金色的，带着微弱的脉动。每一个字都像是被光照亮。

在画面最底部，地面开始显现——不是草地，而是苔藓覆盖的岩石，上面有古老的符文，像人类的第一个文字。

**内容文案**：
- 标题方向：震撼的宣告。“You Are Alive.” / “The Signal is Gone.”
- 正文方向：直接的情感冲击。“看。没有推送。没有通知。没有红色的小圆点。只有这些光——它们从地面升起，穿过你的身体，在你的脊椎里燃烧。你没有在刷屏。你在呼吸。真正的、完整的、从脚底到头顶的呼吸。欢迎回来。”

**动画叙事（高潮级别）**：
- **主导动画**：巨树的脉动系统——树干内部的流光使用 `<canvas>` 粒子系统模拟血液流动。约 200 个粒子沿树干路径移动，速度随机，透明度随机。粒子的颜色从金色渐变到琥珀色。
- **光点系统**：约 500 个光点从地面升起。每个光点有独立的：起始位置（随机）、速度（0.5-2px/帧）、大小（2-8px）、透明度（0.3-1）、路径（直线或S形）。使用 canvas 渲染。
- **文字动画**：标题使用 SplitType 拆分为字符。每个字符从底部升起（y: 50px → 0），同时模糊从 10px 到 0。但顺序不是从左到右，而是从中心向两侧扩散——像心脏跳动。
- **地面符文**：古老符文使用 SVG 绘制，每个符文从模糊到清晰，像被刻进石头。使用 stroke-dashoffset 动画。
- **环境音效**（可选）：使用 Web Audio API 生成低沉的、持续的蜂鸣音，频率随滚动变化（从 100Hz 到 50Hz），模拟“心跳稳定下来”的感觉。

**为什么用户会记住它**：
因为这是第一次滚动时，用户会不自觉地放慢速度——这个章节的设计就是让你暂停、深呼吸。光点从地面升起的画面，直接触发人类对“生命”和“希望”的原始反应。巨树内部的流光则是“万物有灵”的视觉化呈现。

class ParticleSystem {
  constructor(count) {
    this.canvas = document.querySelector('.particle-canvas');
    this.ctx = this.canvas.getContext('2d');
    this.particles = [];
    this.running = false;
    
    for (let i = 0; i < count; i++) {
      this.particles.push({
        x: Math.random() * this.canvas.width,
        y: this.canvas.height + Math.random() * 200,
        size: 2 + Math.random() * 6,
        speed: 0.5 + Math.random() * 2,
        opacity: 0.3 + Math.random() * 0.7,
        phase: Math.random() * Math.PI * 2,
        wobble: Math.random() * 50

    this.animate();

    if (!this.running) return;
    this.ctx.clearRect(0, 0, this.canvas.width, this.canvas.height);
    
    this.particles.forEach(p => {
      p.y -= p.speed;
      p.x += Math.sin(p.phase + p.y * 0.01) * 0.5;
      
      if (p.y < -50) {
        p.y = this.canvas.height + 50;
        p.x = Math.random() * this.canvas.width;

      this.ctx.beginPath();
      this.ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
      this.ctx.fillStyle = `rgba(249, 240, 227, ${p.opacity * (1 - p.y / this.canvas.height)})`;
      this.ctx.fill();
    });
    
    requestAnimationFrame(() => this.animate());
  }
}
